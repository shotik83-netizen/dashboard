# Дашборд — база подрядчиков

Автономное приложение в одном `index.html`. Стили, скрипты и распаковщик встроены. Сервер, сборка и сетевые зависимости не требуются.

Откройте `index.html` → «Администрирование» → выберите базу .xlsx. Для GitHub Pages используйте этот каталог как корень репозитория. В опубликованном приложении база автоматически читается из `data/base.xlsx` по ссылке `sourceUrl` в `config/config.json`. Это предоставленный пользователем Excel без изменений. Для обновления замените книгу по тому же пути либо укажите другой прямой адрес в администрировании и скачайте конфиг. `config.example.json` содержит шаблон без ссылки.

Семь фильтров из письма: выручка за прошлый календарный год, география, предприятие, вид работ, тип объектов, наименование и ИНН. Выбор десяти групп полей, карточка подрядчика, свод, выгрузка настоящего XLSX со всеми строками сегмента и условиями отбора.

Данные обрабатываются в памяти страницы; localStorage, IndexedDB, cookies и фоновые опросы не используются. Excel читается по сохранённым результатам формул. Формулы не пересчитываются.

Настройки: Администрирование → Сохранить и скачать. Импорт JSON и ссылки на конфиг и Excel находятся в администрировании. При открытии по HTTP(S) приложение читает `config/config.json` или ссылку из `?config=…`, затем базу из `sourceUrl`. Ссылку на другой конфиг можно применить кнопкой «Прочитать конфиг». Изменения сохраните как `config.json` и вручную разместите на SharePoint. В администрировании есть ссылка запуска приложения с этим конфигом. Переключатель «День / Ночь» доступен в шапке, тема сохраняется в конфиге (`theme`). Старая конфигурация schemaVersion 1 совместима. `config.example.json` показывает текущий мэппинг. Годы выручки определяются по заголовкам. Предприятия обозначены в исходнике как «Проект 1», «Проект 2»; для реальных названий настройте соответствия столбцов.

Поддерживаются современные Chrome, Edge, Firefox и Safari. Книги .xlsx до 40 МБ; архив до 200 МБ распакованных данных. Загрузка по ссылке требует доступного прямого адреса и разрешения CORS. SharePoint: скачать базу и выбрать файл — надёжный способ при ограничениях сервера.
